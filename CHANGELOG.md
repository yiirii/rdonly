# Changelog

## 0.1.0 — 2026-11-21
First build of Rd Only.
- Library with cover grid, newest-first or A–Z sorting.
- Import EPUB, PDF and CBZ files (button, or drag and drop on the laptop). Titles, authors, series and covers are read from the files.
- The same file is never added twice; a lost file can be re-imported to restore it.
- Books are kept in the app's own storage. On iPhone the app asks to keep that storage permanently, and Settings shows whether it agreed.
- Works offline on iPhone and updates itself quietly when a new version is published.
- Laptop: portable Windows app (no install step).
