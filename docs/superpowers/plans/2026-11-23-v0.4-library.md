# v0.4 Organisation & Library Look Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** A library that organises itself and feels alive: status tabs, collections, tags, search, filters, sort, multi-select, a Continue card, and quirky flat-shape motion.
**Spec:** `docs/superpowers/specs/2026-11-21-reader-design.md` §5.2 (collections, collectionItems), §6, §8. Mockup approved with changes: `docs/design/v0.4-library-mockup.png`.

## Decisions (Justin, 2026-11-23)
- Collections are mainly reading lists; a book can be in any number. Tabs along the top: **All · Reading · Not started · Finished**, then collections (each with a colour dot, reorder by drag, long-press/right-click → Rename / Colour / Delete), then **+**.
- Status is automatic: Not started = never opened; Reading = opened, not finished; Finished = reached last page (≥ 98%) or marked; "Mark as finished / not finished" in the book menu overrides.
- Series in status tabs show as folders holding only the matching volumes.
- Search field at the top (/ focuses on laptop) over title, author, series and **free-form tags** (new: `book.tags: string[]`, edited in Edit details).
- Sort: **Recently added** (default), Recently read, Title A–Z. The **last-read book** is a big Continue card at the top (tinted with its cover's colour); the grid below follows the chosen sort.
- Type chips under the tabs, multi-pick, combine with tab + search.
- Covers: thin progress bar; cover-size slider (local setting `coverSize`: 0.75–1.4).
- Multi-select (long-press then tap others on phone; Ctrl/Shift-click on laptop) → Add to collection, Add tag, Delete.
- Add to collection: from the book menu (checkbox list) and by dragging a cover onto a tab (laptop).
- Phone: Continue card scrolls away; search + tabs stick to the top.
- Header gets a clear **Settings** button.
- Motion: quirky but refined, basic flat shapes, muted colours (see Task 6).

## Data
- `books`: + `tags?: string[]`, `finished?: boolean` (manual override; undefined = automatic).
- `progress`: unchanged (updatedAt = last read).
- `collections`: `{ id, name, color, order, updatedAt }`; `collectionItems`: `{ id: '<collectionId>:<bookId>', collectionId, bookId, updatedAt }` (records, so adding on two devices never clobbers).

## Review Focus
1. A book deleted while in collections → no ghost entries; collection counts right.
2. Search + chips + tab together with series folders → folders show only matching volumes; empty results show a friendly empty state.
3. Reordering tabs, renaming to an existing name, deleting a collection (books stay in the library).
4. Multi-select across a series folder; Escape/back leaves selection mode.
5. Progress for 100-book libraries: library view stays smooth (no per-card store subscriptions storm).
