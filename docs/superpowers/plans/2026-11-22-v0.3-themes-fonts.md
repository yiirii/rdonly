# v0.3 Themes & Fonts Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Justin's curated look for reading: 7 characterful fonts + book's own, 14 page colours, size / line spacing / margins / two-column controls, and per-device page-turn style (Glide, Fold, Scroll).
**Spec:** `docs/superpowers/specs/2026-11-21-reader-design.md` §5.3, §7, §8. Decisions (with Justin, 2026-11-22; specimens in `docs/design/`):
- Fonts: Newsreader (default), Vollkorn, Spectral, Instrument Sans, Funnel Sans, Host Grotesk, Atkinson Hyperlegible Next, Book's own. (Instrument Sans assumed — question skipped.)
- Themes (bg/fg): Paper #f4efe4/#2b2722, Linen #efebe5/#33302c, Sepia #e9dcc3/#3b2f22, Parchment #e2d0ab/#3a2c18, Rose #f0e2dc/#3a2926, Sage #dde4d3/#2b3327, Mist #e1e7ee/#26303b, Dusk #2b2734/#d9d1c7, Slate #23282f/#c8d0d8, Night #1c1d21/#cfcac0, Ink #131a25/#c2cad6, Forest #17201b/#c6d1c2, Ember #1d1714/#d8b88e, OLED #000000/#a9a49a.
- Controls: text size, line spacing, margins (narrow/normal/wide), two columns (laptop only). Page turn default Glide; Fold and Scroll offered; Slide dropped (it was the scroll animation Justin disliked).
- Synced: theme, font, lineHeight, margins. Local-only: fontSize, pageTurn, columns, haptics.

## Review Focus
1. Switching font/theme mid-chapter keeps the reading position (no jump to chapter start).
2. Fonts load offline (bundled, precached) and inside the book frame on iPhone and in Electron (file://).
3. Fold/Glide never leave an overlay or faded page behind (rapid turns, reduced motion).
4. Scroll mode saves and restores position.
5. A setting saved on an older version (e.g. font 'literata') falls back to the new default.

### Task 1: Fonts + themes data
- `src/reader/novel/fonts.ts` FONTS (id, name, family, scale), `fontFaces()`; `themes.ts` READING_THEMES (14). Unit: ids/order, contrast 7–15 each, tone matches bg luminance, unknown saved font/theme → default.
### Task 2: Settings + Aa sheet controls
- `settings.ts`: lineHeight (1.4|1.6|1.8), margins ('narrow'|'normal'|'wide'), columns (bool, local), pageTurn ('glide'|'fold'|'scroll', local). E2E: each control changes the book frame (line-height, padding/margin attr, max-column-count, font-family), position kept after font change.
### Task 3: Page-turn styles
- Fold overlay (solid theme-coloured panel + hard edge sweeping with transform), Scroll = foliate flow 'scrolled'. E2E: fold overlay appears mid-turn and is gone after; scroll mode sets flow=scrolled and restores position after reopen.
### Task 4: App book font → Newsreader; release v0.3.0 (smoke, perf, review, installer link).
