# v0.2 Open Every Book Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tap a cover and read it — novels, manga, webtoons, comics and PDFs each open in the right mode, remember your place, and can be edited or deleted.

**Architecture:** A hash route (`#/read/{bookId}`) swaps the library for a `ReaderScreen` that loads the book's file as a `Blob` and hands it to one of four mode components behind a common `ReaderMode` interface: `NovelMode` (vendored foliate-js), `PagedComicMode` (LTR/RTL, spreads), `WebtoonMode` (virtualised strip), `PdfMode` (pdf.js). Comic pages come from a `PageSource` that reads archives with random access over the Blob (ZIP via our own central-directory reader + fflate; RAR/7z via libarchive.js), so a 150 MB volume is never fully in memory. Progress is a `progress` record per book, saved debounced.

**Tech Stack:** existing v0.1 stack + vendored foliate-js @ `78914aef` (MIT), libarchive.js 2.x (WASM worker), @fontsource Literata / Lora / Atkinson Hyperlegible.

**Spec:** `docs/superpowers/specs/2026-11-21-reader-design.md` (§5.2 `progress`, §7 modes, §8 look, §11 build order, §11.1 edit/delete).

## Global Constraints

- All v0.1 Global Constraints still hold (no gradients; transform/opacity-only animation; reduced motion; dark default; keycap/bead/1px top edge; never weaken an animation for performance without asking).
- `progress` record: `{ id: bookId, updatedAt, locator: string, percent: number (0–1), mode: ReaderModeName }`. Saved at most every 15 s while reading, and immediately on leaving the reader or when the page is hidden.
- Mode names: `'novel' | 'paged-ltr' | 'paged-rtl' | 'webtoon' | 'pdf'`. Default by tag: novel→novel, manga→paged-rtl, comic→paged-ltr, webtoon→webtoon, document→pdf. `book.modeOverride` wins.
- Spreads only when the reader is ≥ 900 px wide and landscape; a page wider than tall is always shown alone; first page alone by default.
- Starter reading themes (v0.2 only; full set is v0.3): **Paper** `#f4efe4`/`#2b2722`, **Sepia** `#e9dcc3`/`#3b2f22`, **Night** `#1c1d21`/`#cfcac0`, **OLED** `#000000`/`#a9a49a`. Starter fonts: Literata (default), Lora, Atkinson Hyperlegible, plus "Book's own".
- Reader chrome: tap the middle third to show/hide bars; bars auto-hide after 3 s of no interaction; left/right thirds turn pages (mirrored in RTL); arrow keys and wheel on laptop; Escape or Back returns to the library.
- Every new version bumps `package.json` version (phones only update on a newer version).

## Review Focus

1. **Huge archive (≥150 MB CBZ) on the phone** → opens without reading the whole file into memory; only nearby pages decoded. (Task 2 test: page read touches only that entry's byte range)
2. **Damaged page inside an otherwise good comic** → that page shows a flat "This page couldn't be read" tile; the rest of the book reads. (Task 4 test)
3. **File missing on this device** (deleted from storage) → tapping the cover shows "File missing — import it again to read" instead of a broken reader. (Task 1 test)
4. **Leaving mid-book via Back, app switch, or closing the window** → reopening lands on the same page. (Tasks 1, 7 tests)
5. **Unusual EPUB** (no TOC, fixed-layout, embedded fonts, missing cover) → opens and paginates; fixed-layout EPUBs render as pages. (Task 7 test with a fixed-layout fixture)
